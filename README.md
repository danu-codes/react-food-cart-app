# 🍔 React Food Cart App

A modern food ordering cart system built using **React.js**.  
Users can browse food items, add/remove them from cart, and see real-time total price updates.

---

## 🚀 Features

- 🍕 Browse food products
- 🛒 Add / Remove items from cart
- 💰 Automatic total price calculation
- 🔥 Highlight latest food items
- 🎨 Modern responsive UI
- ⚡ Fast and smooth React state updates

---

## 🛠️ Tech Stack

- React.js (Vite / CRA)
- JavaScript (ES6+)
- CSS3
- React Router DOM
